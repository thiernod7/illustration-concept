# Suivi des conteneurs — Madina (Conakry)

Maquette : `index.html`, une page autonome avec des données d'exemple. Le concept est décrit dans [`CLAUDE.md`](CLAUDE.md).

Pour la voir en local, ouvrez `index.html` dans un navigateur.

## Publication sur GitHub Pages

Adresse : https://thiernod7.github.io/illustration-concept/

Le workflow `.github/workflows/pages.yml` publie `index.html` à chaque push sur la branche par défaut du dépôt. On peut aussi le lancer à la main depuis l'onglet Actions.

À faire une fois : *Settings → Pages → Build and deployment → Source : GitHub Actions*.
